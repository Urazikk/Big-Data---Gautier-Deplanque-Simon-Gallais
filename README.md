# Big Data Processing - ECE Fall 2026

Lab work for the Big Data Processing course.

**Authors:** Gautier Deplanque, Simon Gallais

## Contents

| Lab | Topic | Folder |
|-----|-------|--------|
| Lab 1 | Unstructured data analysis with Spark RDDs (word count) | [`lab01-word-count`](lab01-word-count) |

Each lab folder has its own README (what is done, main results, how to run it) and an executed
notebook that can be read directly on GitHub.

## Environment

The labs run in the Jupyter Docker Stacks image `quay.io/jupyter/pyspark-notebook`
(Spark + Python + Jupyter). See the README of each lab for the exact command.
